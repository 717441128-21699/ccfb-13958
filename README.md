# 树芯年轮测量与交叉定年系统（网页版）

在浏览器里完成树芯扫描图的**自动边界识别 → 早晚材分测 → 伪轮/缺轮提示 → 人工增删改即时重算 → COFECHA 风格交叉定年 → 同树多芯合并 → 样地年表**全流程。边界识别与定年算法全部用 **TypeScript** 写成纯函数模块，可独立单测、可被任何前端/Node 环境复用。

## 运行

```bash
npm install
npm run dev        # 开发服务器，浏览器打开提示的 /src/ui/index.html
npm run build      # 类型检查 + 生产构建到 dist/
npm run test       # Vitest 单元/链路测试（17 个）
npx tsx scripts/e2e-smoke.ts   # Node 端端到端冒烟，打印识别/定年/年表指标
```

页面右上角：
- **载入合成演示数据**：生成 1 个样地、5 棵树 × 2 芯 + 1 根独立盲测芯，每芯刻意注入 1 个缺轮、2 个伪轮；
- **导入扫描图**：导入真实高清扫描图（PNG/JPG），默认按 900 DPI 等效标定，可在数据模型里改 `scaleMmPerPx`；
- 地址加 `?autodemo=1` 可一键自动跑通全流程（自检用），再加 `&tab=dating|chronology|truth` 直接定位面板。

画布操作：滚轮缩放、空白拖动平移、拖动边界线改位置、双击空白加边界、右键边界删除；**任何修改后年宽与已定年结果立即重算**。

## 关键算法口径

**边界识别**
1. 条带平均得到灰度剖面，高通基线校正去光照不均，高斯平滑；
2. 中心化差分求梯度，自适应阈值取强边界「种子峰」；
3. **周期性先验**：用种子峰间距中位数估年轮周期，从首峰顺序跟踪、每周期开窗选最强局部峰并在线更新周期——弱边界靠周期约束找回，伪轮暗带因处于两轮之间且梯度弱而不落峰；
4. 晚材 = 紧邻外边界的暗带，输出早材/晚材宽度与晚材率；
5. 伪轮 = 早材内局部基线下的窄暗谷；缺轮 = 宽度异常偏大的轮（第一轮髓心端豁免）；弱边界按梯度置信度标注。

**交叉定年（COFECHA 惯例）**
- 对重叠段做一阶差分后算 Pearson 相关 `r`；
- `t = r·sqrt((n−2)/(1−r²))`；
- GLK 逐年宽窄变化符号一致率（零差计半次）；
- 50 年窗口、25 年步进的分段 `t`，定位对不上的时段；
- 最佳错位下，差分反向且标准化偏离 ≥1.5σ 的年份标为异常；
- **缺轮诊断**：异常宽轮而参考年表无对应宽年 → 提示缺轮（缺轮未补时年份随整体错位，补轮重算即归位）。

**年表**：同树多芯逐年平均成树序列；每条序列负指数去趋势得指数，样地内按年取 biweight 稳健均值，附样本深度、平均敏感度等。

## 合成数据与准确率核对

`synthetic.ts` 按真实生长规律造数据：负指数树龄趋势 ×（共享气候信号 + 个体噪声），气候含低频振荡、AR(1) 与标志性窄/宽年；缺轮表现为该年不生成晚材边界（宽度并入前一年），伪轮是只贯穿条带中部、对比更弱的暗线。所有随机数种子化，结果可复现，并输出边界/年宽/异常的完整真值。

当前合成数据集上的实测指标（见 `e2e-smoke` 与测试）：

| 指标 | 结果 |
|---|---|
| 边界召回率（容差 6px，约 0.2mm） | **99%**（700 条边界，误检峰 1 个） |
| 匹配边界平均位置误差 | 约 3.4 px（≈0.12 mm） |
| 伪轮提示 | 17/20，且基本不被误判为真边界 |
| 缺轮（图像+定年联合） | 定年端点偏量恰好等于缺轮数；补轮后端点归位、r/t 显著提升 |
| 盲测定年 | 缺轮未补 t=6.00；人工补轮后 r 0.594→0.804、t 6.00→11.16 |

> 说明：宽度取整到 **0.01 mm**。合成图 1mm≈28px（约 900 DPI 量级），真实扫描图按实际标尺设置 `scaleMmPerPx`。

## 已知边界（设计取舍）

- 测量路径目前为水平直路径（条带平均），斜芯/弯曲路径可在 `extractProfile` 基础上扩展为折线采样；
- 参考年表当前用合成气候信号占位，接入所里标准年表时替换 `setReference` 的 `{years, widths}` 即可，定年逻辑不变；
- 缺轮的最终确认保留给人工（行业惯例），系统负责把可疑位置和定年错位量显式标出。
